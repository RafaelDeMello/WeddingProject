# Fontes

Arquivos `.woff2` (subset latin) do [Fontsource](https://fontsource.org), versão **5.3.0**, baixados de
`https://cdn.jsdelivr.net/npm/@fontsource/<família>@5.3.0/files/`. Servidos pelo próprio app (CSP `default-src 'self'`).
Escolhidas pelas artes impressas do casamento (cardápio, placa de mesa e cartões de nome).

| Família | Pesos | Uso | Referência na arte |
|---|---|---|---|
| Pinyon Script | 400 | títulos decorativos curtos (nome do evento, "Obrigado!") | "Menu", "Mesa", "Sr. e Sra. Mello" |
| Oranienbaum | 400 | títulos de seção, números, monograma "A&R" | "ENTRADAS", "JANTAR", datas |
| Courier Prime | 700 | nome do convidado, em caixa alta | cartões de nome |
| Lora | 400, 600 | textos, botões e instruções | itens do cardápio |

Todas sob a SIL Open Font License 1.1 — ver `OFL-*.txt`.
